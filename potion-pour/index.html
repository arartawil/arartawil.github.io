Potion Pour: Color Sort Puzzle

Potion Pour is a relaxing color-sort puzzle. Pour potions between flasks on the alchemist's shelf until each flask holds one color, with no timer and no pressure.

  • 1,000+ levels and more coming
  • 20 magical worlds
  • Daily Brew challenge with streaks
  • Collectible flask skins
  • Undo, extra flask and restart anytime
  • Colorblind mode
  • English and Arabic, fully offline
